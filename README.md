# Shell Emulator — вариант 12

Практическая работа «Конфигурационное управление», ИКБО-22-25.
Текущий этап: 1. Python 3.12+, консольный интерфейс Windows.
Внешние библиотеки для работы программы не требуются, сборка не нужна.

## Установка, запуск и тесты

Откройте эту папку как проект PyCharm. Создайте Python-окружение `.venv`
в настройках интерпретатора или выполните из корня проекта в PowerShell:

```powershell
py -3 -m venv .venv
.\run.bat
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`run.bat` передаёт все аргументы и код возврата, запускает из корня проекта;
использует `.venv`, затем `py -3` или `python`, если окружения ещё нет.
Прямой запуск: `python -m src.main`. Для него рабочая папка — корень проекта.
Настройки PyCharm и окружение локальны и не входят в Git.

## Структура и требования к коду

`src/` — приложение; `tests/` — unittest; `run.bat` — запуск;
`.gitignore` — исключение окружений, настроек редактора и сборки.
Во всех коммитах присутствуют тесты и README соответствующего этапа.
Ограничения: файл ≤1000 строк; Python-строка ≤80 символов; функция ≤40 строк;
аргументы ≤7; цикломатическая сложность ≤10. Используются docstrings,
snake_case и именованные значения в сравнениях. `tests/test_quality.py`
проверяет структуру и AST. При разработке проверяются flake8 и pep8-naming.

## Ввод и команды

Приглашение `default:~$` содержит имя VFS. Парсер разделяет ввод по пробелам
и другим пробельным символам. Кавычки и escape-последовательности команд
не поддерживаются по варианту 12: используйте виртуальные имена без пробелов.
Пустые строки игнорируются. Неизвестные команды и неверные аргументы
выводят `error:`; REPL продолжает работу. `exit` без аргументов завершает
сеанс. EOF и Ctrl+C также корректно завершают интерактивный ввод.

`ls [путь]` и `cd [путь]` — заглушки: печатают своё имя и аргументы.

## Интерактивная демонстрация ошибок

```text
ls
cd .
unknown
cd a b
exit extra
exit
```

Для этапов 4–5 дополнительные успешные и ошибочные режимы собраны
в startup-скриптах. Очная демонстрация на защите выполняется студентом.

## Функции приложения

### errors.py

- `validate_count` — Проверяет число аргументов по множеству разрешённых значений.

### main.py

- `run_interactive` — Выполняет REPL до exit, EOF или Ctrl+C.
- `main` — Запускает эмулятор и возвращает код завершения процесса.

### parser.py

- `parse_command` — Возвращает команду и аргументы; кавычки не интерпретируются.

### shell.py

- `__init__` — Создаёт сеанс с именем виртуальной файловой системы.
- `prompt` — Возвращает приглашение с именем VFS.
- `execute` — Выполняет команду, преобразуя ожидаемые ошибки в статус.
- `_dispatch` — Вызывает доступную команду или сообщает о неизвестной.
